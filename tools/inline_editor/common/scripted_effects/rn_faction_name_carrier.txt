# Faction-name carrier: the ONE place that stores a player-given faction name. Like the country
# layer (capie_cn_*), the name is its own layer, in variables of the faction LEADER (a faction has no
# variables of its own in script):
#   capie_fn_n      array of character codes
#   capie_fn_ver=1  the layer is set
#   capie_fn_rev    set last by every change; CAPIE then refreshes the faction's name
# Drawing the layer needs CAPIE with the faction layer (proposed API level 5); the Apply checks
# capie_cap first, so an older CAPIE changes nothing and says so. If the leadership moves, the layer
# stays with the former leader and the faction shows the game's name again.
# Scope: the faction leader. ROOT holds the text in rn_pshort / rn_pshort_len (scratch).
