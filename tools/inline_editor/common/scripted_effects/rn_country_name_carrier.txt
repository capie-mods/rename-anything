# Country-name carrier: the ONE place that stores a player-given country name and adjective.
# Since CAPIE 1.2 (API level 4, plugin/capie/CONTRACT.md section 13) the name is its own layer in the
# country's variables, not a cosmetic tag (decision 2026-10-13, docs/API-DECISIONS.md):
#   capie_cn_n / capie_cn_a  arrays of character codes (name / adjective)
#   capie_cn_ver = 1         the layer is set
#   capie_cn_rev             set last by every change; capie_core.dll then refreshes the names
# On screen: this layer > the current cosmetic tag > the base name. Flag and colour stay the game's,
# a later cosmetic tag change by the game keeps the layer, and the reset removes only the layer.
# Legacy: saves of CAPIE 1.0/1.1 carry the name as an RN1 cosmetic tag ("RN1|Name|Adjective|") with the
# flag rn_custom_name. The first Apply or Reset on such a country drops that cosmetic tag (the tag it
# replaced was never stored, so it cannot be restored) and sets rn_cn_migrated, so a later reset done
# by another tool (CAPIE console) is never mistaken for a legacy tag.
# Scope: the country to rename. ROOT holds the text in a buffer pair chosen by temp rn_cn_src:
#   1 = rn_cname / rn_cadj (own country), 2 = rn_pshort / rn_plong (scratch of the subject editor).
